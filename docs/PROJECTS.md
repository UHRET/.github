## ARES Mission Planner

**7Page - UHRET** · [Interplanetary Survival Guide: Martian Map](https://www.spaceappschallenge.org/2026/challenges/interplanetary-survival-guide-martian-map/)

The planner compares shortest and terrain-preferred routes using an eight-direction A* engine, a Jezero CTX optical mosaic and sampled elevation data. The current JavaScript repository contains elevation profiles, a mission library, multi-stop itineraries, JSON export and printable briefings. Measured and synthetic modes serve different purposes. The route weights are illustrative. The research preview runs on Cloudflare Workers Static Assets. No repository-wide license was found on the public default branch.

## EarthSona

**Asteronix - UHRET** · [The Earth Information Jukebox](https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/)

TypeScript, Vite and Web Audio power a map and globe, Data Listening and Ambient playback, Motif and Flow, the Sonification Lab, Library and a sequencer in Studio. The current player samples visible pixels. Quantitative sonification of physical raster values is future work. Code is licensed under GNU GPL version 3. Imagery has separate source credits and terms.

[UHRET fork](https://github.com/oztimurlarmtaluhret/EarthSona) · [Original repository](https://github.com/grassified/EarthSona) · [Reviewed revision](https://github.com/grassified/EarthSona/tree/354219f7ff18db735c6bde40163a79906446f3be) · [Technical source](https://github.com/grassified/EarthSona/blob/354219f7ff18db735c6bde40163a79906446f3be/docs/DATASETS.md) · [NASA team record](https://www.spaceappschallenge.org/2026/find-a-team/asteronix-uhret/) · [Live demo](https://earthsona.netlify.app/)

## CALY: LEFT BEHIND

**Caly's Check Engine Club - UHRET** · [Abandoned but not Forgotten: Storytelling about NASA’s Discarded Equipment on the Moon and Mars](https://www.spaceappschallenge.org/2026/challenges/nasas-discarded-equipment-storytelling/?tab=teams)

Ren’Py 8.5.3 runs the English and Turkish visual novel. The full version has eight discoveries across the Moon and Mars. The Apollo 17 demo covers four lunar discoveries. Both let readers inspect photos, ask questions and revisit sources. Caly and the journey are fictional. No repository-wide license was found. The source record identifies character artwork with unresolved redistribution rights.

## QK norm — BlindSpot Explorer

**Qk norm - UHRET** · [Flame in Freefall: SI-Powered Fire Safety Insights from Microgravity Combustion Data](https://www.spaceappschallenge.org/2026/challenges/flame-in-freefall/)

Python and FastAPI expose a structured experiment catalogue and exploratory models. The dashboard includes Blender teaching models. RAG was removed and scientific validation was deferred. Several model results are weak or negative. Language-model output is excluded as scientific evidence. The repository license is Apache-2.0. Third-party models, data and publications have separate terms.

## Solar Pulse

**Solar Pulse - UHRET** · [Create Health Monitoring Software for Astronauts on Space Missions](https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/)

The public repository contains one README. It describes React, TypeScript, Vite, Python/FastAPI, local Qwen through LM Studio and retrieval over curated NASA sources. Demonstration records illustrate wellness, exercise and scheduling. Implementation and license could not be verified from the public repository. The described prototype has no clinical or operational validation.
