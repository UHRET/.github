# Contributing to UHRET

[Official website](https://oztimurlarmtaluhret.tech/) · [Türkçe profil](profile/README.tr.md)

- Check the project’s contribution guide and license. Start larger changes with an issue or discussion in the relevant repository. Include the problem, context and intended result.
- Start a scoped branch from the default branch. Open a pull request with a short summary, verification steps and known limits. Avoid including unrelated changes.
- Run the checks that fit the change. Add a reproduction for bug fixes, and check both languages when changing bilingual content. Mention checks you could not run.
- Ask a maintainer for review. During hackathons, agree on a lighter review process together and record temporary assumptions or shortcuts for follow-up.
- Keep secrets and private information out of issues, commits and logs. Wait for a maintainer to supply a private channel before sharing sensitive security details.
- Attribute external work and confirm reuse terms for code, datasets, models, media and other assets. Each project retains its own license.

## Katkı

İlgili projenin katkı rehberini ve lisansını incele. Sınırlı kapsamlı bir dalda çalış, değişikliği ve testleri PR’da açıkla, inceleme iste. Zaman kısıtlı yarışmalarda geçici kararları ekipçe kayda al. Gizli bilgileri açık GitHub alanlarına ekleme. Üçüncü taraf içeriklerini kullanmadan önce izinleri ve atıfları kontrol et.
